# webtoon2pdf — 웹페이지 이미지 → PDF 변환기

웹페이지 주소를 넣으면 그 페이지의 큰 이미지를 위에서 아래 순서대로 모아 PDF 전자책으로 만들어 줍니다.
웹툰·만화 뷰어뿐 아니라 블로그, 갤러리, 기사, 상품 상세 등 어떤 사이트든 대상입니다.
"다음" 링크를 따라가면 여러 페이지를 한 권(페이지별 북마크)으로 묶을 수 있습니다.

- Playwright 헤드리스 Chromium으로 실제 렌더링 → 스크롤해야 로드되는 지연 로딩 이미지도 수집
- 이미지 다운로드를 같은 브라우저 컨텍스트로 수행 → Referer·쿠키 검사(핫링크 차단) 통과
- iframe 안의 본문(네이버 블로그, 다음 카페 등)도 수집
- 썸네일이 원본 이미지 파일 링크로 감싸져 있으면 원본을 받음, srcset은 최대 해상도 선택
- 아이콘·광고 배너·추천 썸네일은 크기와 위치로 걸러냄
- 이미지 선택 모드: **자동**(기본) / **큰 이미지 전부** / **웹툰 본문만**
- 중단 후 재실행하면 이어서 진행(`work/` 폴더의 `manifest.json`)

> 개인 소장 용도로만 사용하세요. 사이트 약관과 저작권을 확인하고, 기본 요청 간격을 줄이지 마세요.

## 설치 없이 쓰는 실행 파일(.exe) — 다른 PC 배포용

파이썬을 설치할 수 없는 새 PC에 옮길 때 가장 간편합니다.

1. 이 PC에서 **`빌드.bat`** 더블클릭 → 바탕화면에 `전자책변환기_설치없이_날짜.zip`이 생깁니다(약 67MB). PyInstaller로 파이썬·의존성·Playwright 드라이버를 묶은 단독 실행 파일입니다.
2. 그 zip을 새 PC에 옮겨 **압축을 풉니다**.
3. 푼 폴더의 **`전자책변환기.exe`**를 더블클릭. 파이썬 설치가 필요 없습니다. 바탕화면 아이콘은 같은 폴더의 `바탕화면 바로가기 만들기.bat`으로 만듭니다.
4. 크롬 확장은 `chrome://extensions` → 개발자 모드 → 압축해제된 확장 로드 → `chrome-extension` 폴더.

주소 입력(일일툰 등 캔버스 사이트)은 **크롬이 설치돼 있어야** 동작합니다. 무거운 Chromium(428MB)을 번들하지 않고 시스템 크롬을 쓰기 때문입니다. 저장한 파일·폴더 변환은 크롬 없이도 됩니다. 표지 권 번호 OCR도 실행 파일에 포함됩니다(윈도우 한국어 언어팩 필요).

## 설치 (파이썬 환경)

윈도우에서 가장 쉬운 방법은 **`설치.bat` 더블클릭**입니다. 파이썬만 미리 깔려 있으면(python.org, "Add python.exe to PATH" 체크) `.venv` 생성 → 패키지 설치 → 내장 브라우저 설치 → 바탕화면 바로가기까지 한 번에 됩니다.

수동 설치:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e .
playwright install chromium
```

주소를 직접 넣어 변환할 때는 PC에 설치된 **크롬**을 사용합니다(자동화 티가 덜 남). 크롬이 없으면 위에서 설치한 Playwright 내장 Chromium으로 대신 실행하며, 환경변수 `WEBTOON2PDF_BROWSER=chromium`으로 강제할 수도 있습니다.

## 다른 PC로 옮기기 (윈도우)

1. 이 PC에서 **`내보내기.bat`** 더블클릭 → 바탕화면에 `전자책변환기_복사본_날짜.zip`이 생깁니다. 무거운 `.venv`·`work`·`*.pdf`는 빠지고 소스만(약 13MB) 담깁니다.
2. 그 zip을 USB·메일·카카오톡으로 새 PC에 옮겨 **압축을 풉니다**.
3. 새 PC에서 파이썬을 설치한 뒤(위 참고) 풀린 폴더의 **`설치.bat`** 더블클릭. 끝나면 바탕화면의 **"전자책 변환기"**로 실행합니다.
4. 크롬 확장은 `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드" → `chrome-extension` 폴더 선택.

`.venv`와 `work` 폴더는 PC에 종속이라 **복사하지 마세요**. 새 PC에서 `설치.bat`이 새로 만듭니다. 자세한 안내는 압축 안의 `새PC설치안내.txt`에 있습니다.

## 아이폰·아이패드에서 보기

형식을 **EPUB**으로 두고 변환하면 아이폰·아이패드 기본 **도서(Books)** 앱 (주황색 책 아이콘, 처음부터 설치되어 있음)에서 열리는 전자책이 됩니다.
웹툰처럼 세로로 아주 긴 이미지는 화면에 맞게 빈 줄에서 잘라 여러 페이지로 나눕니다.

파일 옮기기: 결과 `.epub`을 **카카오톡 "나에게 보내기"**로 전송하거나 **iCloud Drive** 폴더에 넣은 뒤,
아이폰에서 그 파일을 열고 공유 → **도서**를 고르면 서재에 추가됩니다. AirDrop도 됩니다.
PDF도 같은 방법으로 도서 앱에서 열립니다.

## 창 프로그램으로 사용하기 (가장 쉬움)

1. 프로젝트 폴더의 `이미지PDF.bat`를 더블클릭합니다. (바탕화면에 바로가기를 만들어 두면 편합니다)
2. 창이 뜨면 **페이지 주소**를 붙여넣고, 저장 위치를 확인합니다. 웹툰처럼 여러 페이지를 이어 받으려면 "'다음' 링크 따라가기" 수를 늘립니다.
3. **[변환 시작]**을 누르면 아래 로그 창에 진행 상황이 표시됩니다.
4. 끝나면 **[결과 열기]** 버튼으로 바로 확인합니다.

수집 과정을 보고 싶으면 "브라우저 창 보기"를 켜세요. 로그인이 필요한 사이트는 "고급 설정"의
[로그인해서 만들기]로 세션을 저장한 뒤 변환하면 됩니다.

### 만화를 "앱 하나로" 모아서 권별 전자책 만들기

로그인·보안확인이 걸리는 만화 사이트는 **크롬 확장으로 모아** 변환하는 것이 안정적입니다.
앱 창 하나에서 전부 진행됩니다(확장은 뒤에서 수집만 담당).

1. 처음 한 번만 **[크롬 확장 설치]** — 확장 폴더가 열리고 설치 3단계를 안내합니다.
2. **[크롬에서 모으기]** → 만화 '첫 화' 주소 입력 → 사용자의 크롬이 열립니다. 크롬에서 확장으로
   "연속 저장"(로그인·보안확인은 직접 통과) → 다 모으면 안내창의 **[다 모았어요 → 분석]**.
3. 앱이 **권 분석 보고**를 띄웁니다 — 표지 기준 "몇 권"인지, 각 권 화 수, 빠진 화, 그리고
   **마지막 권이 완결인지 '미확정'(다음 권 표지가 아직 없음)** 인지. 여러 번 나눠 모아도 되고,
   쌓아둔 폴더는 **[권 분석]**으로 다시 확인합니다.
4. **권 묶기 설정**(표지별/N개씩·첫 권 번호·방향)을 확인한 뒤 **[변환 시작]**.

> 모으자마자 바로 변환하지 않는 이유: 만화는 권으로 묶어야 하는데 한 화씩 저장되므로,
> 권 번호가 틀어지지 않도록 **분석 → 확인 → 변환** 순서로 진행합니다.
> 표지가 없는 소스(예: '미리보기')는 권을 자동으로 못 나누므로 'N개씩'과 '첫 권 번호'로 지정하세요.

## 명령줄로 사용하기

```bash
webtoon2pdf grab "https://example.com/webtoon/123/episode/1" -o 내웹툰.pdf
```

주요 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-o, --output` | `output.pdf` | 결과 파일 경로 (`--split`이면 폴더). 확장자는 형식에 맞게 바뀜 |
| `--format` | `pdf` | `pdf` / `epub`(아이폰·아이패드 도서 앱) / `both` |
| `--title` | 없음 | 책 제목 |
| `--max-chapters` | 50 | 따라갈 최대 회차 수 |
| `--mode` | `auto` | `auto` / `all`(큰 이미지 전부) / `webtoon`(본문 구간만) |
| `--min-width` | 300 | 포함할 최소 이미지 폭(px). 표시 폭과 원본 폭 중 큰 값 기준 |
| `--delay` | 0.3 | 이미지 요청 간격(초) |
| `--headed` | 꺼짐 | 브라우저 창을 보이게 실행 |
| `--cookies FILE` | 없음 | `login` 명령으로 저장한 세션 파일 |
| `--next-selector CSS` | 자동 | 다음 화 링크를 직접 지정 |
| `--split` | 꺼짐 | 회차별 PDF로 따로 저장 |
| `--keep-images` | 꺼짐 | 원본 이미지를 `work/`에 남김 |
| `--fit-width` | 꺼짐 | 가장 흔한 폭에 맞춰 리사이즈 |

로그인이 필요한 사이트

```bash
webtoon2pdf login "https://example.com/login" -o storage_state.json
webtoon2pdf grab "https://example.com/webtoon/123/episode/1" --cookies storage_state.json
```

다음 화 링크를 못 찾을 때는 `--headed`로 열어 링크 요소를 확인한 뒤 selector를 지정합니다.

```bash
webtoon2pdf grab "<url>" --next-selector "a.btn_next"
```

## 크롬 확장 설치 (한 번만) — 단축키로 페이지 저장

봇 차단 사이트나 `Ctrl+S`를 막아 둔 사이트는 **평소 쓰는 크롬에서 페이지를 저장해 변환**하는 것이 가장 확실합니다.
`chrome-extension/` 폴더의 확장을 설치하면 **`Alt+Shift+S` 한 번**으로 현재 페이지가
`다운로드\webtoon2pdf\<제목>_<시각>.mhtml`로 저장됩니다. 확장 단축키는 브라우저가 처리하므로 페이지가 `Ctrl+S`를 막아도 상관없고,
저장 전에 페이지를 끝까지 자동 스크롤해 지연 로딩 이미지까지 담습니다.

1. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켬
2. **압축해제된 확장 프로그램을 로드합니다** → 이 프로젝트의 `chrome-extension` 폴더 선택
3. 단축키 확인·변경: `chrome://extensions/shortcuts` (기본 `Alt+Shift+S`. Windows에서 Alt+Shift는 한/영 전환과 겹치니 `Ctrl+Shift+S` 등으로 바꾸는 것을 권장)
4. 툴바의 확장 아이콘을 누르면 팝업이 뜹니다: **[이 페이지 저장]** / **[연속 저장 시작]**

저장 중에는 아이콘에 `…`, 끝나면 `✓`, 실패하면 `!` 배지가 표시됩니다.
그림을 `<img>` 대신 `<canvas>`에 그리는 뷰어(페이지 저장을 하면 광고만 남는 사이트)는 자동으로 감지해서,
페이지 스크립트에 들어 있는 원본 이미지 주소 목록을 순서대로 직접 받아 `.mhtml`로 조립합니다(배지에 보라색 진행 숫자).
원본 서버가 외부 읽기(CORS)를 막아 두면 이 방법도 안 되며, 그때는 일반 페이지 저장으로 넘어갑니다.
크롬 설정에서 "다운로드 전에 각 파일의 저장 위치 확인"이 켜져 있으면 저장 대화상자가 뜨니 꺼 두는 게 편합니다.
확장은 보안상 다운로드 폴더 아래에만 저장할 수 있습니다.

### 여러 화 연속 저장 (저장 → 다음화 자동 이동 → 저장 반복)

1. 크롬에서 첫 회차 페이지를 열고 **`Ctrl+Shift+S`**(또는 주소창 옆 퍼즐 아이콘 → "webtoon2pdf 페이지 저장") → 저장 창이 뜨면 "이 페이지부터 N화 저장"에 원하는 수 입력 → **Enter** 또는 **[연속 저장 시작]**. **지금 열린 페이지가 1화째**로 들어갑니다(예: 12화에서 5 입력 → 12~16화).
   (Ctrl+Alt+글자 조합은 크롬이 확장 단축키로 허용하지 않습니다. 키를 바꾸려면 `chrome://extensions/shortcuts`의 "저장 창 열기")
2. 현재 회차를 저장한 뒤 페이지의 "다음화"류 링크·버튼(`rel=next` → "다음화/다음 화/next" 텍스트 → class/id에 next → href 없는 버튼 클릭)을 찾아 이동하고, 로드가 끝나면 2초 쉬고 다시 저장합니다. 아이콘 배지에 `3/20`처럼 진행 상황이 표시됩니다.
3. 중단 조건: N화 도달, 다음 링크 없음, 이미 저장한 회차로 되돌아옴, 다른 사이트로 나감, 탭 닫힘, 팝업의 **[중지]**.
   이동한 페이지가 보안 확인이면 자동 우회하지 않고 멈춰서 기다립니다(배지 `!`). 크롬 창에서 직접 통과하면 이어서 진행합니다(최대 120초).
   그림이 다 뜰 때까지 기다린 뒤(지연 로딩을 한꺼번에 받게 하고 끝까지 훑음, 최대 60초) 저장하며, 팝업에 회차마다 "그림 대기 N초·저장 N초"가 표시됩니다.
   그래도 로드가 안 끝난 그림이 있으면 **저장하지 않고**
   새로고침을 한 번 한 뒤, 그래도 안 되면 멈춰서 기다립니다(최대 3분). 크롬 창에서 그 회차 그림이 보이게 하면 이어갑니다.
   (뷰어가 광고 확인 뒤에야 그림을 넣는 사이트에서 광고만 담긴 파일이 생기는 것을 막기 위한 동작입니다. 이런 사이트는 10화 이하로 나눠 저장하는 편이 안전합니다.)
4. 파일은 `다운로드\webtoon2pdf\B<시각>_<번호>_<제목>.mhtml`로 저장됩니다. 같은 배치는 접두가 같고 번호순으로 정렬됩니다.
5. 변환기에서 **[최근 저장 파일]**을 누르면 마지막 배치 전체가 한 번에 들어오고, 권 나누기 옵션대로 한 권 또는 여러 권으로 만들어집니다.

연속 저장 시작/중지를 단축키로 쓰려면 `chrome://extensions/shortcuts`에서 "연속 저장 시작/중지"에 키를 지정하세요(기본 키 없음).

## 안 되는 경우

- **"보안 확인이 필요합니다"라고 나오거나, 사람인지 확인이 계속 반복될 때 / Ctrl+S가 안 먹는 사이트**:
  사이트가 Cloudflare 같은 봇 차단을 쓰고 자동화 브라우저를 거부하는 것입니다. 이 도구는 확인을 자동으로 통과하거나 우회하지
  않습니다. 위의 크롬 확장을 설치한 뒤:
  1. 크롬에서 그 페이지를 열고 확인을 통과합니다.
  2. `Alt+Shift+S`를 누릅니다. (확장을 안 깔았다면 `Ctrl+S` → **"웹페이지, 단일 파일"(.mhtml)** 또는 **"웹페이지, 전체"**로 저장)
  3. 변환기에서 **[최근 저장 파일]**을 누르면 방금 저장한 파일이 들어옵니다. (직접 고르려면 **[파일 열기]**) → [변환 시작]

## 동작 순서

1. 페이지 로드 → 끝까지 스크롤하며 지연 로딩 트리거 → 모든 이미지 로드 대기
2. DOM에서 `<img>`, `<picture>`, CSS 배경 이미지 수집(srcset은 최대 해상도, `data-src` 우선)
3. 필터: 최소 폭 미만·고정 요소·중복 제거. `auto` 모드는 폭이 비슷한 이미지가 연속되는 구간이 페이지 이미지 높이의 85% 이상이면(웹툰형) 그 구간만, 아니면(블로그·갤러리형) 큰 이미지 전부를 고름. 웹툰형은 양끝에서 본문과 다른 경로에서 온 낮은 이미지(연령 안내, 광고 배너)를 제거
4. 브라우저 컨텍스트로 다운로드(Referer·쿠키 자동). 실패 시 요소 스크린샷으로 대체
5. `rel=next` → "다음화"류 텍스트 링크 → class/id에 `next` 순으로 다음 링크 탐지. 링크가 없고 버튼만 있으면(네이버 웹툰 등) 버튼을 클릭해 URL이 바뀌는지 확인. 같은 도메인만, 재방문 시 중단
6. WebP·투명 PNG는 JPEG로 정규화. PDF는 원본을 무손실로 삽입하고 회차별 북마크 추가. EPUB은 한 장에 한 페이지, 긴 이미지는 여백에서 분할, 회차별 목차

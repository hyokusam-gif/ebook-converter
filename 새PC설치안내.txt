========================================
 전자책 변환기 - 새 PC에서 쓰기 (설치 불필요)
========================================

이 폴더는 파이썬 설치 없이 바로 쓰는 실행 파일입니다.


[1] 이 폴더(압축을 푼 폴더)에서 "전자책변환기.exe" 를 더블클릭
  - 파란 화면에 "Windows의 PC 보호" 경고가 뜨면 "추가 정보" - "실행"을 누르세요
  - 파이썬이나 다른 설치가 전혀 필요 없습니다


[2] (선택) 바탕화면에 아이콘 만들기
  - 같은 폴더의 "바탕화면 바로가기 만들기.bat" 를 더블클릭하면
    바탕화면에 "전자책 변환기" 아이콘이 생깁니다


-------------------------------------
 앱 하나로 쓰는 흐름 (만화 모으기 → 전자책)
-------------------------------------
앱 창 하나에서 전부 됩니다. 크롬 확장은 뒤에서 도와주는 역할이에요.

  1) 처음 한 번만: 앱의 [크롬 확장 설치] 버튼을 누르고 안내대로 설치
     (아래 "크롬 확장 설치"와 같은 과정을, 앱이 폴더까지 열어 줍니다)
  2) [크롬에서 모으기] 버튼 → 만화 '첫 화' 주소를 넣으면 크롬이 열립니다
     → 크롬에서 확장으로 '연속 저장'(로그인·보안확인은 직접 통과)
     → 다 모으면 [다 모았어요 → 분석]
  3) 앱이 "몇 권인지 / 마지막 권이 다 모였는지"를 분석해 알려 줍니다
     (여러 번 나눠 모아도 됩니다. 쌓아둔 폴더는 [권 분석]으로 다시 확인)
  4) 권 묶기 설정(표지별/N개씩·첫 권 번호·방향)을 확인한 뒤 [변환 시작]

  * 바로 변환하지 않고 '분석 → 확인 → 변환' 순서인 이유:
    만화는 권으로 묶어야 하는데 한 화씩 저장되므로, 권 번호가 틀어지지 않게
    사람이 한 번 확인하고 변환합니다.


-------------------------------------
 크롬 확장 직접 설치 (앱의 [크롬 확장 설치]가 하는 일)
-------------------------------------
  1) 크롬 주소창에 chrome://extensions 입력
  2) 오른쪽 위 "개발자 모드" 켜기
  3) "압축해제된 확장 프로그램을 로드합니다" 클릭
  4) 이 폴더 안의 "chrome-extension" 폴더 선택
  - 연속 저장: 확장 팝업의 "연속 저장 시작" (또는 Ctrl+Shift+S)
  - 현재 페이지만 저장: Alt+Shift+S


-------------------------------------
 참고
-------------------------------------
- "주소를 직접 넣어 받기"(일일툰 같은 사이트)는 이 PC에 크롬이
  설치돼 있어야 동작합니다. (크롬 확장을 쓰려면 어차피 크롬이 필요합니다)
  저장한 파일이나 폴더를 변환하는 것은 크롬 없이도 됩니다.
- 표지의 권 번호 자동 읽기(OCR)는 윈도우 한국어 언어팩이 있어야 합니다.
  없어도 변환은 정상이며, 권 번호만 "첫 권 번호"부터 차례로 붙습니다.
- 만든 결과물(EPUB/PDF)은 기본적으로 바탕화면에 저장됩니다.
